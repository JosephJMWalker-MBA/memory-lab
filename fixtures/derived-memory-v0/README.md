# Derived-memory v0 synthetic evidence

This fixture is entirely fictional. It exists to test derived-memory semantics
without requiring a private corpus, retrieval system, embedding model, or LLM.

Each evidence item contains human-readable synthetic text plus a deliberately
normalized assertion. The normalization step is treated as given in v0. The
research question begins after normalization: can a derived record remain
traceable to evidence, survive contradiction, distinguish world-state change
from interpretation change, and be revised by a backward attribution check?

The cases cover:

- stable fact with later corroboration;
- temporal state change;
- conflicting simultaneous claims;
- explicit correction;
- evolving relationship;
- unsupported inference and revision.

No fixture text is derived from the private recovered corpus.
